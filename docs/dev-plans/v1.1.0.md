## 六、技术方案

### 6.1 桌面小组件

**技术选型**: Glance (Jetpack Compose for AppWidgets)

**文件结构**:
```
ui/widget/
├── MusicWidget.kt                 # GlanceAppWidget
├── MusicWidgetReceiver.kt         # AppWidgetProvider
├── MusicWidgetWorker.kt           # WorkManager
└── MusicWidgetState.kt            # 状态数据

res/xml/
└── music_widget_info.xml          # 元数据
```

**数据流**:
```
PlayerSession/DataStore → MusicWidgetWorker → MusicWidget.updateAll() → GlanceAppWidget UI
```

**交互**:
- 播放/暂停/上一曲/下一曲 → PendingIntent → PlayerService
- 点击小组件 → MainActivity

### 6.2 播放列表增强

#### 重命名功能

```
PlaylistDao.updateName() → PlaylistRepo.renamePlaylist() → RenamePlaylistUseCase → UI
```

#### 收藏功能

**方案**: 独立 FavoriteEntity 表

```kotlin
@Entity(tableName = "favorites")
data class FavoriteEntity(
    @PrimaryKey @ColumnInfo(name = "song_id") val songId: Long,
    @ColumnInfo(name = "created_at") val createdAt: Long
)
```

**迁移**:
```kotlin
val MIGRATION_11_12 = object : Migration(11, 12) {
    override fun migrate(db: SupportSQLiteDatabase) {
        db.execSQL("""
            CREATE TABLE IF NOT EXISTS favorites (
                song_id INTEGER NOT NULL PRIMARY KEY,
                created_at INTEGER NOT NULL,
                FOREIGN KEY (song_id) REFERENCES songs(id) ON DELETE CASCADE
            )
        """)
        db.execSQL("ALTER TABLE queue ADD COLUMN sort_order INTEGER NOT NULL DEFAULT 0")
    }
}
```
